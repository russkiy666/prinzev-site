# Курс-платформа

Кабинет ученика для онлайн-обучения в бело-синем стиле.

## Разделы
- **Мой путь** — прогресс, текущий этап, следующий шаг, ответ куратора, часы обучения
- **Уроки** — модули по этапам, плеер, материалы, отметка «пройден»
- **Задания** — статусы: Нужно сдать / На проверке / На доработке / Принято / Закрыто
- **Обратная связь** — запрос разбора задания, вопроса по уроку или созвона

## Как устроено
Один файл `index.html`, без сборки. Содержимое курса — объект `SEED` в скрипте, стартовые статусы — `DEFAULT_STATE`.
Сейчас прогресс хранится в браузере ученика (localStorage).
